# ================================== 一、灵感箱编辑器统一

当前问题：

灵感箱编辑依然使用旧弹窗。

风格与分类编辑器不一致。

整改：

参考：

分类编辑器。

统一使用：

右侧 Drawer。

要求：

- fixed 定位
- 从右侧滑出
- 毛玻璃背景
- 圆角
- 阴影
- 动画

不要：

浏览器风格弹窗。

不要：

普通 Modal。

灵感编辑与分类编辑保持统一体验。

# ================================== 二、分类编辑器定位修复

当前问题：

页面向下滚动后。

编辑面板跟着页面移动。

出现错位。

这是 bug。

整改：

编辑器必须：

position: fixed

固定在：

右侧。

不参与页面滚动。

要求：

- 页面怎么滚动都不影响编辑器位置
- 编辑器永远贴右侧
- 高度固定 100vh
- 内容区域内部滚动

参考：

Notion

Linear

# ================================== 三、标签云视觉重构

当前问题：

标签球效果太丑。

像随机散落的 div。

没有质感。

没有记忆瓶感觉。

整改：

参考概念：

Memory Jar（记忆瓶）

目标：

透明玻璃瓶中装满彩色记忆球。

要求：

1. 小球彼此靠近。

不要均匀分散。

不要满屏乱飞。

1. 小球聚集。

形成真实瓶中堆叠效果。

1. 使用透明度：

opacity

backdrop blur

glass effect

1. 小球颜色柔和。

不要高饱和。

1. 使用次数越高：

球越大。

1. 标签文字居中。
2. 小球允许轻微重叠。
3. 整体更像：

装满糖果的玻璃瓶。

而不是：

散点图。

# ================================== 七、人生地图滚动逻辑重构

当前问题：

人生地图页面：

内部滚动区域过多。

导致：

页面底部只有很小区域可以滚动。

体验极差。

整改：

取消：

地点区域内部滚动。

取消：

地图区域内部滚动。

改成：

整个页面统一滚动。

要求：

1. 主内容区域滚动。
2. 地图区域自适应高度。
3. 地点列表正常排列。
4. 不出现：

嵌套滚动条。

1. 不出现：

需要把鼠标移到特定小区域才能滚动。

参考：

Airbnb

Apple Maps
